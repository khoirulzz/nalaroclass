## Classroom snapshots

`public/images/class-themes/` contains all ten themes in the current `CLASS_THEMES` catalog. Captured from real `ClassThemeScope`, `ClassOverview`, `ClassWorkspaceNav`, `ClassSummary`, Card and world-art components using synthetic classroom data at 1120 x 1080, with reduced motion. No production API requests or user data. Source baseline: `a3ae259`.

To refresh after classroom design changes: start Vite, run `node workers/scripts/capture-landing-themes.mjs`, then convert PNGs in `workers/.wrangler/landing-theme-captures/` to WebP in the public directory. The catalog drives both capture and landing options. These are static previews; world animation remains in the application.
